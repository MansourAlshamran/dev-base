DevBase (This Website!)

DevBase is a personal developer knowledge base designed to organize technical concepts, learning resources, and practical projects in one structured platform.

Built with HTML, CSS, and JavaScript, it focuses on responsive layouts, semantic web structure, reusable UI components, interactive animations, and clean frontend architecture. The project also serves as a practical environment for applying and documenting new development concepts as they are learned.

Nukhbah Recruit

Nukhbah Recruit is an AI-powered recruitment platform designed specifically for technical roles where traditional hiring methods often fail to measure real technical ability.

The system processes candidate CVs, analyzes job requirements, and uses embeddings with similarity matching to identify relevant candidates. It then generates role-specific technical assessments based on the job, industry, and experience level, evaluates candidate responses using LLMs, and produces structured results to support more consistent and scalable technical hiring decisions.
